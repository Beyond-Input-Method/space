# 响应式计算器

一个美观、功能完整的响应式HTML计算器，支持多种设备和分辨率。

## 功能特性

### 基础功能
- ✅ 基本四则运算（加、减、乘、除）
- ✅ 百分比计算
- ✅ 小数点运算
- ✅ 清除功能（C清除所有，CE清除当前）
- ✅ 退格功能
- ✅ 表达式显示

### 响应式设计
- 📱 **手机端**（320px - 768px）：紧凑布局，触摸优化
- 📱 **小手机端**（320px - 480px）：进一步优化小屏显示
- 📱 **平板端**（768px - 1024px）：中等尺寸，平衡布局
- 💻 **PC端**（1024px+）：大屏优化，宽松布局
- 🔄 **横屏适配**：自动适应横屏模式
- 🌙 **深色模式**：支持系统深色模式

### 交互体验
- ⌨️ **键盘支持**：完整的键盘快捷键
- 👆 **触摸优化**：针对触摸设备优化
- 📳 **触觉反馈**：支持设备的触觉反馈
- 🎨 **动画效果**：流畅的按钮动画和悬停效果
- ♿ **无障碍**：支持减少动画偏好

### 高级特性
- 💾 **状态保存**：页面切换时自动保存计算状态
- 🔢 **数字格式化**：大数字自动添加千分位分隔符
- 🔬 **科学计数法**：超长数字自动转换为科学计数法
- 🚫 **错误处理**：除零错误、溢出错误等
- 🔄 **屏幕旋转**：自动适应屏幕旋转

## 使用方法

### 在线访问
直接在浏览器中打开 `index.html` 文件即可使用。

### 键盘快捷键
- **数字键**：`0-9` 输入数字
- **操作符**：`+`, `-`, `*`, `/`, `%` 输入操作符
- **等号**：`=` 或 `Enter` 执行计算
- **小数点**：`.` 或 `,` 输入小数点
- **退格**：`Backspace` 删除最后一个字符
- **清除**：`Escape` 或 `C` 清除所有
- **清除当前**：`Delete` 清除当前输入

### 触摸操作
- 点击数字按钮输入数字
- 点击操作符按钮进行运算
- 支持长按和快速点击
- 防止意外的双击缩放
